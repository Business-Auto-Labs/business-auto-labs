# Business Automation Labs

Responsive, accessible static website built with semantic HTML, CSS, and vanilla JavaScript. No build step or framework required.

## Start here

1. Open this folder in VS Code.
2. Read docs/CODE_WALKTHROUGH.md alongside index.html, css/styles.css, and js/main.js.
3. Set a monitored contact inbox in js/config.js.
4. The canonical URL is set to https://code-neel.github.io/business-auto-labs/. If you later configure a custom domain, update index.html, robots.txt, and sitemap.xml together.
5. Preview in VS Code with Live Preview/Live Server or run python -m http.server 8000 here and open http://localhost:8000.

## Project map

- index.html — page content, accessibility landmarks, SEO/social metadata, and limited structured data.
- css/styles.css — visual tokens, layout, responsive rules, and reduced-motion behavior.
- js/config.js — public contact configuration.
- js/main.js — progressive enhancements for navigation, date, email, and hero.
- assets/ — SVG favicon and social preview.
- robots.txt, sitemap.xml — crawler files containing a domain placeholder.
- docs/ — architecture, code, design, deployment, search, and learning guides.

## Before launch

The business email is configured. The domain is still a placeholder; founder details and real portfolio examples need verified content. Founder names and bios, real portfolio entries, and specific contact details still need verified content. No claims, projects, testimonials, certifications, or performance metrics are invented. GitHub Pages is static, so there is no server-side form; the contact link opens an email draft.

See docs/DEPLOYMENT.md and docs/SEO_GUIDE.md before making the site public. Deployment and Google indexing are not performed or guaranteed by this project.
