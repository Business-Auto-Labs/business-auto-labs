# Business Automation Labs


Responsive, accessible static website built with semantic HTML, CSS, and vanilla JavaScript. No build step or framework required.


## Start here


1. Open this folder in VS Code.
2. Read docs/CODE_WALKTHROUGH.md alongside index.html, css/styles.css, and js/main.js.
3. The public contact email is configured in js/config.js.
4. The canonical URL uses https://business-auto-labs.github.io/business-auto-labs/. If you later configure a custom domain, update index.html, robots.txt, and sitemap.xml together.
5. Preview in VS Code with Live Preview/Live Server or run python -m http.server 8000 here and open http://localhost:8000.


## Project map


- index.html — page content, accessibility landmarks, SEO/social metadata, and limited structured data.
- css/styles.css — visual tokens, layout, responsive rules, and reduced-motion behavior.
- js/config.js — public email configuration.
- js/main.js — progressive enhancements for navigation, date, email, and hero.
- assets/ — SVG favicon and social preview.
- robots.txt, sitemap.xml — crawler files with the current GitHub Pages URL.
- docs/ — architecture, code, design, deployment, search, and learning guides.


## Content and launch notes


The business email and phone numbers are configured. Founder names and biographies, along with real portfolio entries, still need verified content. No claims, projects, testimonials, certifications, or performance metrics are invented. GitHub Pages is static, so the contact links use mailto and tel rather than a server-side form.


See docs/DEPLOYMENT.md and docs/SEO_GUIDE.md for GitHub Pages, custom domain, HTTPS, and Search Console guidance. Google indexing is not guaranteed; submitting a sitemap is a discovery hint, not a promise.
