# Glossary

- Canonical URL: the preferred public address for a page.
- CSS custom property: a reusable value declared in CSS and referenced with var().
- DNS: records that connect a domain name to a hosting service.
- GitHub Pages: static website hosting provided through a GitHub repository.
- JSON-LD: a format for machine-readable structured data embedded in a page.
- Mailto link: a link that asks the visitor's device to open an email application.
- Open Graph: metadata used by social sites to create link previews.
- Progressive enhancement: optional behavior added while keeping core content usable without it.
- Responsive design: layouts that adapt to different screens and input methods.
- Sitemap: a list of public addresses offered to search crawlers.
- Structured data: machine-readable descriptions of page entities; it does not promise special search results.
